# EchoEmber

EchoEmber is a real-time, event-driven data-streaming orchestrator for scalable system deployments.

EchoEmber is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/EchoEmber.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure EchoEmber, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
